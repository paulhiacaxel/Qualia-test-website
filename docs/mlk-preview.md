# MLK Mural — proposal preview

Route: `/previews/mlk-mural`.

Prepared October 13, 2026 for Kyle Holbrook / Moving Lives of Kids. This is an
unlisted editorial proposal, with `noindex`, `nofollow`, and `nocache` metadata.
The URL is accessible to anyone who receives it. It does not create a listing,
show availability, collect payment, or imply host approval. No links were added
to discovery or the public navigation.

## Scope and approval

The private lesson concept draws on the artist's existing “Paint a Wynwood
Mural” offering. The page labels its session flow as a proposal. The published
60–90 minute duration is identified as a reference, not a confirmed Qualia
duration. Price, materials, guest ages, format, location, project permission,
image use and dates remain for the host to confirm. No charitable donation,
fund allocation, audience, demand, insurance or safety guarantee is promised.

Feedback goes to `contact@bookqualia.com`. Normal host onboarding and Qualia
listing review are still required before a bookable listing is published.
