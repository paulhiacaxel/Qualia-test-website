# Qualia social artwork — draft

Created October 12, 2026 (Miami time). No social account or post has been published by creating these files.

Editable SVG masters retain the existing Qualia aperture and wordmark. Text is editable; Fraunces, Inter and IBM Plex Mono WOFF2 fonts are embedded for consistent offline previews. Full font licenses are in `FONT-LICENSES.txt` and embedded in each SVG’s metadata. Each file stem below includes an editable `.svg` master and a full-canvas `.png` export. PNGs were rendered directly from the SVGs with Inkscape using locally installed matching Fraunces, Inter and IBM Plex Mono fonts. They retain the stated canvas dimensions without cropping. No synthetic photography or image editing is used. These exports have not yet been uploaded to any social platform.

- `01-meet-qualia`: 1080 × 1350. Brand introduction.
- `02-founding-hosts`: 1080 × 1350. First 30 hosts; approved 3-booking-or-3-month offer.
- `03-how-qualia-works`: 1080 × 1350. Request/acceptance/payment order; first collection still in progress.
- `story-host-invitation`: 1080 × 1920. Host recruitment story companion. Leave link sticker placement for the actual signed-in interface.
- `linkedin-cover-draft`: 1512 × 256. LinkedIn Company Page cover draft; matches the current documented Page cover size.
- `facebook-cover-draft`: 1640 × 720. Editable landscape draft.

The LinkedIn Company Page cover uses the [currently documented 1512 × 256 size](https://www.linkedin.com/help/linkedin/answer/a563309/image-specifications-for-your-linkedin-pages-and-career-pages?lang=en), with PNG accepted below 3 MB. The other dimensions are working canvas sizes, not a claim of current platform requirements. Verify each live platform’s current upload constraints, mobile/desktop crops and avatar overlay before upload. Artwork, captions and handles are drafts for owner review. No fabricated follower counts, testimonials, host photographs or booked experiences.

Use `../qualia-avatar-1024.png` for the profile image. Its mark has uniformly moss-colored rings and spokes.
